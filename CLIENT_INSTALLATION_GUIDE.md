## **🎯 Installation Options for Your Client**

### **Option 1: Installer Package (Recommended)**

#### **For Windows:**
1. Download `DataSense-Setup-1.0.0.exe`
2. Double-click the installer
3. Follow the installation wizard
4. DataSense will appear in Start Menu and Desktop
5. Double-click the DataSense icon to launch

#### **For Mac:**
1. Download `DataSense-1.0.0.dmg`
2. Double-click the DMG file
3. Drag DataSense to Applications folder
4. Launch from Applications or Spotlight search
5. DataSense will appear in Dock when running

#### **For Linux:**
1. Download `DataSense-1.0.0.AppImage`
2. Make it executable: `chmod +x DataSense-1.0.0.AppImage`
3. Double-click to run
4. (Optional) Move to `/usr/local/bin` for system-wide access

---

### **Option 2: Portable Version**

#### **All Platforms:**
1. Download the portable package
2. Extract to any folder (Desktop, Documents, etc.)
3. Double-click `DataSense.exe` (Windows) or `DataSense` (Mac/Linux)
4. No installation required - runs from any location

## **🎮 How to Use DataSense Desktop App**

### **🚀 Launching the App:**
- **Windows:** Start Menu → DataSense, or Desktop shortcut
- **Mac:** Applications → DataSense, or Spotlight search "DataSense"
- **Linux:** Applications menu, or double-click AppImage

### **📁 Importing RLD Files:**
1. Click the **"Import RLD File"** button in the main dashboard
2. Select your `.rld` file using the native file dialog
3. The app automatically converts and stores the data
4. Data appears immediately on the dashboard

### **📊 Using the Dashboard:**
- **Real-time Charts** - Interactive data visualization
- **Status Panel** - System health monitoring
- **Library** - Browse all imported files
- **Settings** - Configure the application

### **🔄 Auto-Processing:**
- **Email Automation** - Automatically processes RLD files from emails
- **Background Processing** - Runs continuously
- **Notifications** - Desktop notifications for new data

## **📞 Support and Troubleshooting**

### **If DataSense Won't Start:**
1. **Windows:** Right-click → "Run as Administrator"
2. **Mac:** System Preferences → Security → Allow DataSense
3. **Linux:** Ensure executable permissions: `chmod +x DataSense.AppImage`

### **If Import Fails:**
1. Check that the file is a valid `.rld` file
2. Ensure the file isn't corrupted
3. Try a different RLD file to test

### **Performance Tips:**
- Close other applications for better performance
- Ensure sufficient disk space for data storage
- Keep the app updated for best performance
